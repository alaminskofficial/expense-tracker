# Expense Tracker App (React Native)

A modern and scalable mobile Expense Tracker built using **React Native (Expo)** to help users manage their personal finances efficiently.

## Features

* Add and manage income & expenses
* Category-wise tracking with color-coded UI
* Clean and modern card-based design
* Time-based insights:

  * Daily
  * Weekly
  * Monthly
  * Yearly summaries
* Total expense overview dashboard
* Empty state handling
* Scalable architecture for future enhancements

## Tech Stack

* React Native (Expo)
* TypeScript
* React Navigation (Stack + Tabs)
* Tailwind for React Native (twrnc)
* Functional component architecture

## Project Structure

* Modular folder structure (`screens`, `components`, `navigation`, `types`)
* Reusable UI components
* Type-safe models for scalability

## More  Features

* Expense filtering by date range
* Category-wise analytics (charts)
* Local storage / database integration
* Edit & delete expenses
* Authentication & cloud sync
